# 🐍 GA-Python

Små Python-prosjekter som vi live-koder sammen med studenter på **Gokstad Akademiet**.
Målet er å vise hvordan det dere lærer i timene fungerer i praksis – ett lite prosjekt om gangen.

Prosjektene er sortert etter **uke**. Hver mappe inneholder koden slik den så ut da vi var ferdige den uken.

## 🚀 Kom i gang

1. Installer [Python 3](https://www.python.org/downloads/) hvis du ikke har det fra før.
2. Last ned prosjektet – trykk på den grønne **Code**-knappen og velg **Download ZIP**, eller klon det:

   ```bash
   git clone https://github.com/osonvisen/GA-Python.git
   ```

3. Gå inn i mappen for uken du vil se på, og kjør filen:

   ```bash
   cd Week38
   python cupGame.py
   ```

> 💡 **Tips:** Bruker du Mac, kan det hende du må skrive `python3` i stedet for `python`.

## 📅 Uke 38 – Lister, filer og løkker

📁 Mappe: [`Week38`](Week38)

| Fil | Hva den gjør | Dette øver vi på |
|-----|--------------|------------------|
| [`cupGame.py`](Week38/cupGame.py) | Koppespillet: koppene blandes, og du gjetter hvilken kopp mynten ligger under 🪙 | `random`, lister, bytte plass på elementer, `input()` og `if/else` |
